## Download a released build

Choose your computer below. Each link always downloads the latest published build.

| Platform | Recommended package | Notes |
|---|---|---|
| macOS Apple silicon | [Download `.dmg`](https://github.com/markmushian/markbot/releases/latest/download/MarkBot-arm64.dmg) | Drag to Applications. Unsigned: right-click → **Open** the first time. |
| macOS Intel | [Download `.dmg`](https://github.com/markmushian/markbot/releases/latest/download/MarkBot-x64.dmg) | Same app for Intel Macs. Unsigned: right-click → **Open**. |
| Windows x64 | [Download installer](https://github.com/markmushian/markbot/releases/latest/download/MarkBot-setup.exe) | Per-user installer; Windows signing is not yet available. |
| Ubuntu 24.04 x64 | [Download `.deb`](https://github.com/markmushian/markbot/releases/latest/download/MarkBot-x64.deb) · [AppImage](https://github.com/markmushian/markbot/releases/latest/download/MarkBot-x64.AppImage) | The `.deb` is recommended; the AppImage is portable. |

<Callout type="warn" title="Windows SmartScreen">
  The Windows installer is not code-signed yet. Windows may show “Unknown publisher.” Verify that you downloaded it from the official Mark Bot releases repository before choosing **More info → Run anyway**.
</Callout>

## Install an agent CLI

Mark Bot needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart Mark Bot.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Using Mark Bot at work

If your company uses OpenMaus Admin, you can sign in with your organization to use the AI models it provides, alongside your own. It is optional. See [Use Mark Bot at work](./organisation.mdx).

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/milind-soni/OpenMausBot.git
cd Mark Bot
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

Mark Bot stores its application data under `~/.markbot`. Electron window and browser data use the normal per-platform application data directory.
